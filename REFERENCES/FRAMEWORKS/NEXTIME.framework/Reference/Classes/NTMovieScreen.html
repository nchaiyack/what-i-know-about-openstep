NTMovieScreen


Inherits From: NSControl : NSView : NSResponder : NSObject


Conforms To: NSCoding (NSResponder)


Declared In: NEXTIME/NTMovieScreen.h



Class Description


An NTMovieScreen is an NSControl in which you can display a NEXTIME movie.  To show a particular movie, invoke setMovieFile:.  The user can then play or pause the movie by clicking anywhere in the NTMovieScreen.


The NTMovieScreen class uses an NTMovieScreenCell to implement most of its behavior.  Another class can be substituted by invoking setCellClass:.


See the NTMovieScreenCell class description for more information.

Class Methods 


cellClass


+ (Class)cellClass 


Returns the class that was set by setCellClass:.  If setCellClass: has never been invoked, the NTMovieScreenCell class is returned by default.



setCellClass:


+ (void)setCellClass:(Class)class 


Configures the NTMovieScreen class to use instances of class for its NSCells.  class should be the NTMovieScreenCell class or a subclass of  NTMovieScreenCell.  To obtain a value for class, send the class message to the desired class object or to an instance of that class.  The default class is NTMovieScreenCell.


See the NSControl class specification for more information on setCellClass:.


See also:  + cellClass



Instance Methods


movieFile


- (NSString *)movieFile


Returns the absolute pathname of the movie file that's currently displayed by the receiver.  If there is no movie file, an empty string is returned.


See also:  - setMovieFile:



setMovieFile:


- (BOOL)setMovieFile:(NSString *)path 


Opens the movie file path and displays the new movie.  path should be an absolute pathname.  This method creates an NTMovieDocument and sends it an initByReferencingFile: message.  The NTMovieDocument is made the represented object of the receiver's NTMovieScreenCell.  The movie's poster frame is then displayed.  Returns YES if path is a valid movie file, NO otherwise.


See also:  - movieFile
