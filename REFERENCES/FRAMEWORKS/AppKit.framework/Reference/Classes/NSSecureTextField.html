Class Description


NSSecureTextField is a subclass of NSTextField that hides its text from display or other access via the user interface. It's suitable for use as a password-entry object, or for any item in which a secure value must be kept. An NSSecureTextField uses an NSSecureTextFieldCell, and adds behavior to the OPENSTEP extended text system to protect its text value. Your code can get the text field's string value using the standard stringValue method, but users can't extract it themselves. NSSecureTextField overrides many aspects of text editing to prevent passing of the object's value out by mechanisms available to the user (namely, through Cut, Copy, and Paste commands, and the Services facility). This object also overrides the text system's drawing routine to draw no text at all.
