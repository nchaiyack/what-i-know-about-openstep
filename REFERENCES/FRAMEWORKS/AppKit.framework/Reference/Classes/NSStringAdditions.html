Declared In: AppKit/NSStringDrawing.h



Class Description


The Application Kit adds three methods to support drawing string objects directly in an NSView. These methods, drawAtPoint:withAttributes:, drawInRect:withAttributes:, and sizeWithAttributes:, parallel similar methods defined by NSAttributedString methods. The draw... methods draw a string object with a single set of attributes that apply to the entire string. To draw a string using multiple fonts and other attributes, you must use an NSAttributedString.

Instance Methods


p drawAtPoint:


- (void)drawAtPoint:(NSPoint)aPoint withAttributes:(NSDictionary *)attributes


Draws the receiver with the font and other display attributes of attributes, at aPoint in the currently focused NSView. Don't invoke this method while no NSView is focused. 


See also: - lockFocus (NSView)



p drawInRect:


- (void)drawInRect:(NSRect)aRect withAttributes:(NSDictionary *)attributes


Draws the receiver with the font and other display attributes of attributes, within aRect in the currently focused NSView. Don't invoke this method while no NSView is focused. 


See also: - lockFocus (NSView)



p size


- (NSSize)sizeWithAttributes:(NSDictionary *)attributes
