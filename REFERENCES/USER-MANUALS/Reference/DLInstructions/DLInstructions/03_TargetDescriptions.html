OpenStep Developer's Bookshelf

Target Descriptions

This file describes many of the targets that you might include on your personal bookshelf.  After each description is a audience profile that suggests which developers will find the target most useful.  


If you are viewing this file in an Edit or EditClassic window, you can drag the targets listed here directly into your bookshelf.



General Targets

These targets group several documentation resources into one. They can be useful when you have a question but are not sure where where to start looking.  


Tasks and Concepts — All task-based and conceptual manuals on your system. 

Audience: Developers new to OpenStep

Reference — All reference manuals (Development Environment Reference, and so forth) on your system (excluding framework reference documentation). 

Audience: Developers new to OpenStep


Release Notes — Notes applicable to this release concerning new features, known bugs, and so on.

Audience: All developers


Conceptual Material

Introduction to OpenStep Programming — Through tutorials and conceptual overviews, guides you through the creation of three OpenStep applications and provides an introduction to the development environment, the Objective-C language, and the OpenStep frameworks. <<forthcoming>>

Audience: Developers new to OpenStep 

Object-Oriented Programming and the Objective-C Language — Describes the Objective-C language, the language used to implement the OpenStep frameworks.

Audience: All OpenStep developers

Programmer's Guide to the OpenStep Development Environment — Shows you how to use the major tools (Project Builder, Interface Builder, and so forth) to create and debug OpenStep applications, tools, libraries, frameworks, and other programs. <<forthcoming>>

Audience: All developers

OpenStep Conversion Guide —Describes how to convert applications, libraries, and other software based on NEXTSTEP Release 3 to the OpenStep-compliant 4.0 release.  When you install the ConversionGuideDoc package, this guide is copied to /NextLibrary/Documentation/NextDev/Conversion.

Audience: Developers who need to convert an earlier release of their software.

Topics in OpenStep Programming — Provides conceptual overviews of selected areas of OpenStep programming.

Audience: All OpenStep developers



Reference Material

OpenStep Development Tools Reference — A reference to the tools used in the development environment, such as cc, ld, and gdb. <<forthcoming>>

Audience: All OpenStep developers

OpenStep General Reference — Detailed, comprehensive descriptions of various OpenStep software components. Framework reference documentation is not included in the OpenStep General Reference; the following two targets contain documentation for the most commonly-used frameworks.

Audience: All OpenStep developers


Application Kit Reference — Detailed, comprehensive descriptions of the Application Kit framework.

Audience: All OpenStep developers


Foundation Reference — Detailed, comprehensive descriptions of the Foundation framework.

Audience: All OpenStep developers


UNIX Manual — The "man pages" from the UNIX programmer's manual.

Audience: Developers concentrating on operating system, UNIX, and device driver development


Operating System — A description of Mach operating system software.  The next  target is a chapter of this manual that is of particular interest to those writing device drivers.

Audience: Developers concentrating on operating system, UNIX, and device driver development


Device Driver Kit — The chapter of the Operating System manual that describes the Device Driver Kit.

Audience: Developers concentrating on device driver development


Other Resources


Examples — Source code for sample applications.  For those who want to build these applications, the source code can be found in /NextDeveloper/Examples.

Audience: All developers

Headers — All of the Objective-C, C, and C++ headers on the system.

Audience: All developers
