OpenStep Developer's Bookshelf

Finding Other Targets

The NextDeveloper bookshelf offers a number of useful targets. However, there are many more to choose from.


Finding Additional Targets

Some less frequently used manuals aren't listed in the NextDeveloper bookshelf. To add them, use the File Viewer to navigate to /NextLibrary/Documentation. You can add as targets any of the directories—or subdirectories—you find there. Framework documentation is located within the framework; you can add framework documentation by navigating to the appropriate directory (for example, Foundation framework reference documentation is located in /NextLibrary/Frameworks/Foundation.framework/

Resources/English.lproj/Documentation/Reference).


1 Drag the icon for the directory from the File Viewer to the bookshelf.

2 Choose Save from the Bookshelf menu.



Fine-Tuning Existing Targets

Once you begin to learn where things are in the OpenStep

Developer's Library, you can focus your searches by replacing general targets (such as Reference) with more specific ones. Simply remove the general target by dragging it out of your bookshelf and then drag in the more specific subdirectory, as described above.
