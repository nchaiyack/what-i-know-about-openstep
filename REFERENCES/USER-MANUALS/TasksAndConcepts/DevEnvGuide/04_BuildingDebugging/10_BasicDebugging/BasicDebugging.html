Building and Debugging


10 Basic Debugging


The Project Builder Launch panel provides an interface to the Free Software 

Foundation's gdb debugger. You can set breakpoints, step through source code 

a line at a time, and examine the values of variables. The panel also allows you 

to perform any and all gdb commands and to run programs outside of the debugger.
