12 Creating Frameworks and Dynamic Shared Libraries


Framework and Library are similar project types. The only difference is 

in the packaging. To create either one, you specify which headers to publish 

to its users and set up any precompiled headers. Another concern when 

updating an exisitng framework is changing the version number in such a 

way that you don't break users' programs.
