2.  Currency Converter Tutorial


Currency Converter is a simple application that, given an exchange rate, converts a dollar amount to an amount in a foreign currency. In creating this application, you'll learn the basics of using the development applications (Project Builder and Interface Builder) to compose a user interface, manage an project, define a custom subclass, and build an application.
