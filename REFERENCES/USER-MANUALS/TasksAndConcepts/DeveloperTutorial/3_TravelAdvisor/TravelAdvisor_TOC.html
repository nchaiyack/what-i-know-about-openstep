3.  Travel Advisor Tutorial


Travel Advisor is a forms-based application with which users can enter, modify, and delete information on countries they travel to.  You'll learn in this tutorial how to use some important Foundation classes, how to set up some additional Interface Builder objects, how to use Project Builder to find information, and many other aspects of OpenStep programming.
